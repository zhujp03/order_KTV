桌号 / 包厢二维码

输入数量后自动生成。包厢格式：1包、2包...；桌子格式：1号桌、2号桌...

每个二维码 token 固定，可长期使用；如泄露可单独重置。每桌/包厢还有访问码，客人需输入访问码才能点单。

反追踪 / 隐私默认策略（雏形版）

系统默认不接入第三方统计、不加载第三方字体脚本、不记录设备指纹；订单只关联“二维码 token + 桌号/包厢标签”，用于本地内网与 AWS 公网一致部署。
